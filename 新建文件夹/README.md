# make-knowledge-cards

把用户粘贴的文本或本地 Markdown/TXT 文件，提炼成 5～8 张结构化知识卡片，方便学习与复习。

## 1. 项目解决什么问题

学习、读书、看文章时常见三个痛点：

- **信息过载**：一篇长文读完了，说不清到底讲了几个重点，更记不住
- **复习低效**：原文结构松散、重复啰嗦，想回看要点只能重读全文
- **整理成本高**：手动做笔记费时，且容易抄下次要内容、漏掉关键结论

本项目用一个 AI Agent Skill（`make-knowledge-cards`）解决这些问题：自动通读输入文本，提取**真正重要**的知识点，去重后组装成一组**单点聚焦**的知识卡片，直接输出为 Markdown，拿来即用。

核心原则：**宁缺毋滥**——只提炼原文实际包含的信息，不编造、不延伸；信息不足时如实减少卡片数量，不强行凑数。

## 2. 主要功能

- **文本 → 知识卡片**：输入用户粘贴的文本，或本地 `.md` / `.txt` 文件，输出 5～8 张结构化知识卡片
- **四要素卡片**：每张卡片固定包含「标题、核心知识、简明解释、例子或自测问题」，可直接用于学习与复习
- **智能提取与去重**：只保留支撑主旨的核心概念、关键机制、可复用结论；重复内容自动合并
- **单点聚焦**：一张卡片只讲一个知识点，不堆砌
- **不硬凑数量**：知识点少于 5 个时如实输出（最少 1 张）并在末尾说明；超过 8 个时保留最重要的 8 个
- **纯提示词驱动**：Skill 本体不包含任何脚本，无运行时依赖

### 卡片结构规范

| 要素 | 说明 |
| --- | --- |
| 标题 | 一句话点出知识点（约 20 字内），优先沿用原文术语，不自创概念词 |
| 核心知识 | 原文信息的准确浓缩（1～3 句），关键数字、术语原样保留 |
| 简明解释 | 通俗化说明（2～4 句），可含类比或原文例子，不得引入原文之外的错误事实 |
| 例子或自测问题 | 优先用原文例子；否则构造自测问题，答案必须能从卡片内容推出（每张 1 个） |

### 质量红线

- **不编造**：卡片中每个事实、数字、结论都必须来自原文，宁缺毋滥
- **不重复**：任何两个知识点不得实质相同
- **不堆砌**：一张卡片只讲一个知识点，不做多知识点合并
- **不硬凑**：信息不足时减少数量并说明，不用空话或常识填充

### 支持与不支持

**支持**：用户粘贴的纯文本；本地 Markdown（.md）、TXT（.txt）文件。

**暂不支持**：网页抓取（需用户粘贴内容或提供本地文件）、PDF 及其他格式、Anki 导入格式导出、图形界面卡片。

## 3. 安装方法

本项目的交付物是一个 **AI Agent Skill**（文件夹），安装即把文件夹放入 Agent 的 Skill 识别目录。

**方式 A：作为 Agent Skill 安装（推荐）**

1. 将 `skills/make-knowledge-cards/` 整个目录复制到目标环境对应的 Skill 根目录（如 `workspace/.user_skills/`，路径随环境而异，可参照环境中已有 Skill 的所在目录）
2. 刷新/重启 Agent 会话，Agent 即可在相关需求出现时自动加载本 Skill

**方式 B：项目内直接使用**

在支持 Skill 的 Agent 中，把本项目目录作为工作目录，Agent 会读取 `skills/make-knowledge-cards/SKILL.md` 并按其中流程执行，无需额外安装。

**验证安装**

```bash
# 结构校验（frontmatter 字段、命名规范、description 长度）
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
# 依赖：Python 3 + PyYAML（python -m pip install pyyaml）
# 输出 "Skill is valid!" 即安装正确
```

## 4. 使用方法

在支持 Skill 的 Agent 环境中，说出类似需求即可自动触发，无需指定 Skill 名称：

> - "把这篇笔记做成知识卡片"（随后粘贴文本）
> - "把这个文件整理成学习卡片"（提供本地 .md / .txt 文件路径）
> - "把上面的文字变成知识卡片"（指代上一条消息内容）

Agent 按以下流程执行：

```
获取输入 → 通读提取知识点 → 筛选去重 → 控制数量（5～8 张） → 组装输出
```

- 默认直接在对话中输出全部卡片（Markdown 格式）
- 如需保存，可追加一句"保存为 .md 文件"，Agent 会写成本地文件

## 5. 输入输出示例

**输入**（用户粘贴的文本）：

```
HTTPS 并不是一种全新的协议，它就是在 HTTP 外面套了一层 TLS。
TLS 负责加密数据和校验身份。传输数据先用非对称加密交换会话密钥，
之后用会话密钥做对称加密，因为非对称加密慢、对称加密快。
```

**输出**（Markdown 卡片）：

```
## 卡片 1｜HTTPS = HTTP + TLS

**核心知识**
HTTPS 不是新协议，而是在 HTTP 外层加一层 TLS：TLS 负责加密数据和校验身份，HTTP 仍负责收发请求。

**简明解释**
HTTP 是"快递员"，TLS 是给快递加上的"密封箱 + 防伪标签"，两者分工合作。

**例子或自测问题**
Q：HTTPS 相比 HTTP 多出的那层协议负责哪两件事？
---
```

**真实使用记录**（2026-09-22）：对一段网络安全学习方向介绍（4 个知识点：打基础 / CTF 入门 / 防御侧 / 职业路径）执行首次真实使用，输出 4 张卡片并在末尾注明"原文信息有限，仅提炼出 4 个知识点"，验证了对话指代输入与不足不凑数规则。
